# Mesa de Partes Digital

Prototipo en Python para registrar, consultar y ordenar expedientes.
Curso: Fundamentos de Programación (CIIN1205P) - UPN.

## Módulos
- main.py: menú principal
- validacion.py: valida DNI (8 dígitos), campos y folios
- expedientes.py: genera N.º de expediente, guarda en archivo, busca y ordena por fecha

## Cómo ejecutar
python main.py
